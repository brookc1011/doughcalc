# Real iPhone check — about 10 minutes

Use the HTTPS test app with the reminder server configured. Use a disposable bake. Back up any real data first. If a notification needs longer to arrive, finish the other steps while waiting; record a missing notification rather than marking it passed.

1. **Install:** in Safari, open Share → Add to Home Screen; launch Dough from that icon. Good: no clipped status-bar or home-indicator content. Create the test bake in this installed app; do not assume Safari-tab data is shared.
2. **Plan:** try Eat at, Start at and Both. Open date/time pickers and change a time. Good: fields fit, native controls are legible, mode instructions are short, and an impossible Both plan clearly explains the problem.
3. **Keyboard:** edit room temperature and ball fields, then dismiss the keyboard. Good: no page zoom, sideways movement or hidden focused field; action bars return and remain usable. Save defaults stays above Sizes & diameter.
4. **Lock in:** use a valid Start at plan with the first upcoming reminder a few minutes away. Good: the batch opens once and its times match the preview.
5. **Reminders:** tap Remind me and allow notifications. Leave the app and lock the phone. Good: a notification arrives at the planned time; tapping it opens the intended bake. Ensure Focus mode permits the test notification. If permission was previously denied, check that the app gives useful guidance.
6. **Steps:** mark a step Done; use Choose time on a step, save, then try Undo. Good: time picker fits, changes appear once, and the next-step display updates. Do this after the notification check if it would change the pending reminder.
7. **Rate:** jump to Rate, complete the rating flow and add a test photo and short note. Good: keyboard leaves the note visible, photo appears, and the saved rating is accessible in Bakes.
8. **Back up:** in Settings, export and choose Save to Files in the share sheet. Good: an actual backup file exists. Cancel a second share attempt; check the UI does not imply a cloud copy was saved. Restore testing is a separate check on a disposable profile, not over your only copy.
9. **Navigate:** use in-app back navigation; in a Safari tab, navigate between screens and use the left-edge back gesture. Good: one screen per back action, no sideways scroll or unexpected reset. Installed-app gesture availability may differ; verify in-app navigation there.
10. **Dark and small screens:** enable dark mode; revisit Plan, date fields, info boxes, rating and the dough editor. Rotate once, open the keyboard and try Steps/Recipe/Rate jumps. Good: readable controls, visible headings, no overlapping bars or clipped content. Repeat the keyboard check in a normal Safari tab.

For an issue, send the phone model, OS version, tab vs Home Screen, light/dark setting, exact taps and a screenshot with personal details removed. Never send a personal backup just to report a UI issue.
